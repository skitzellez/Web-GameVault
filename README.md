## ✨ Features

- Free TV channels, retro TV and other websites from Game Vault's **WEB** menu, in the console's own web engine.
- Made for the controller: a pointer on the left stick, no keyboard or mouse needed.
- Blocks pop-up ads and pages trying to download files or ask for permissions.
- Press **B** on a site's first page, or hold **View + Menu**, to go back to Game Vault.

## 🎮 Controls

| Controller | Does |
|---|---|
| Left stick | Move the pointer |
| A | Click |
| Right stick | Scroll |
| B / LB | Back (on the first page: back to the WEB menu) |
| RB | Forward |
| Y | Reload |
| View | Switch between pointer and game controls (for web games) |
| Hold View + Menu | Back to Game Vault |

## 📦 Installation

- **Easiest:** in Game Vault press **RT**, pick **Web** and add it with your phone. Game Vault offers updates there too.
- **With the PC setup:** run the Game Vault setup again; it adds Web for you.
- **By hand:** in Device Portal, **My games & apps → Add**, choose `WebForGameVault_<version>_x64.appx` from the
  [latest release](https://github.com/skitzellez/Web-GameVault/releases/latest).

Requirements: Xbox in Dev Mode with [Game Vault](https://github.com/skitzellez/xbox-game-vault) 0.16.1.478 or newer.

## 🔒 Privacy

Sites you open see you like any web browser would. Game Vault · Web itself sends nothing anywhere.
